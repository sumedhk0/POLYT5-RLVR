# Ambiguity register

Every detail that polyT5 (Sahu et al. 2026) leaves unspecified, together with the choice this repository
makes and why. **If you change one of these, change it here first.** Any result we report must cite the
register version it was produced under.

Status values: `DECIDED` (choice made and implemented) · `OPEN` (not yet needed) · `BLOCKED` (cannot be
resolved from public information).

| ID | Area | What the paper does not say | Our choice | Status |
|---|---|---|---|---|
| **A-01** | Representation | Which backbone bond is "strategically cleaved" after cyclization and canonicalization. Different choices give different PSELFIES for the same polymer. | Default pipeline uses the **direct `[*] → [At]` substitution** (invertible, deterministic, testable). The paper-faithful `psmiles_to_pselfies_loop_break` is also implemented: cyclize → canonicalize → cleave → cap. Cleavage rule: the **lowest canonical-rank single, non-aromatic, in-ring bond**. ⚠️ An earlier draft of this entry said "not in a ring" — that is **wrong**: once the two chain ends are joined, the backbone *is* the macrocycle, so an acyclic-bond filter selects either nothing or a side-chain bridge whose cleavage disconnects the molecule into two fragments. Corrected after implementation; reverting the filter fails 10 tests. | DECIDED |
| **A-04** | Representation | What happens when the repeat unit is too short to cyclize. | **Empirical finding, and it is not a corner case:** joining the two termini requires a one- or two-membered ring whenever both termini sit on the same atom or on two already-bonded atoms. That is **every vinyl polymer** — polyethylene, polypropylene, PVC — plus ortho-phenylene. RDKit cannot represent such rings, so the paper's described pipeline cannot run on them at all. `cyclize_psmiles` returns None and `psmiles_to_pselfies_loop_break` falls back to the direct substitution by default; `fallback_to_direct=False` exposes how often the paper's pipeline actually applies. The paper does not mention this class of polymer. | DECIDED |
| **A-05** | Representation | Whether canonicalizing before cleaving actually removes writing-order bias, as the paper claims ("to mitigate any initial sequence bias"). | **Verified, not assumed:** across 14 different SMILES writings of 4 polymers — reversed chain direction, branch-first, kekulized vs aromatic, `[*]` vs `[At]` — each group collapses to exactly one loop-break PSELFIES, and the groups stay mutually distinct. Deterministic across processes and `PYTHONHASHSEED` values. Implemented via `Chem.CanonicalRankAtoms(breakTies=True)`. | DECIDED |
| **A-02** | Representation | Which canonicalizer is applied to the cyclized intermediate. | RDKit `Chem.MolToSmiles(mol, canonical=True)`, version recorded in the run manifest. | DECIDED |
| **A-03** | Representation | The `selfies` package version. Grammar and alphabet differ materially between v1.x and v2.x. | Pin `selfies>=2.1.1`; the paper's own bracket forms (`[Branch2][Ring1][C]`, `[Ring1][P]`) are v2-consistent. Version recorded per run. | DECIDED |
| **B-01** | Tokenizer | The identity of the 199 base SELFIES tokens (corpus-derived; corpus withheld). | **Derive them from our own training split** — `scripts/build_tokenizer.py --corpus data/processed/pi1m/train.txt` — frequency-ranked, ties broken by token ascending, padded to exactly 199 with explicit reserved placeholders. The library-derived alphabet is retained only as a fallback for when no corpus exists. Measured: 0 unknown tokens on train/val, 3 in 49,411 test sequences. **Do not ship a library-derived alphabet:** it left 2.1% of tokens and 22.4% of sequences as `<unk>` on real data (missing `[/C]`, `[\C]`, `[=At]`, `[/At]`, `[SH1]`, `[2H]`, …). | DECIDED (substituted) |
| **B-02** | Tokenizer | The identity of the 154 conditioning tokens — never enumerated in either version of the paper. | An explicitly enumerated 154-token set of our own design covering the paper's stated categories (property names, digits, `.`, units, operators, booleans, polymer keywords). Listed in full in `src/polyt5/tokenization/vocab.py`. | BLOCKED (substituted) |
| **B-03** | Tokenizer | The literal surface forms of the 5 special tokens; and T5 has no BOS although the paper names a start-of-sequence marker. | `<pad>`, `</s>`, `<unk>`, `<s>`, `▁` (U+2581). `decoder_start_token_id = pad_id` per T5 convention. `<s>` exists so the 5-token count closes. | DECIDED |
| **B-04** | Tokenizer | SentencePiece model type (unigram / BPE / word / char). | None — all tokens are predefined, so we use a deterministic longest-match tokenizer, which is behaviourally identical. Optional `.vocab` side-artifact for interoperability. | DECIDED |

| **C-04** | Architecture | T5 v1.0 (`relu`, tied embeddings) vs v1.1 (`gated-gelu`, untied). | `relu` + `tie_word_embeddings=True` (v1.0), because that is what reproduces the paper's reported parameter counts most closely. | **C-05** | Architecture | Weight-initialization scheme. | T5's initializer scheme scaled by `initializer_factor`. | DECIDED |

| **D-01** | Span corruption | Order in which the three "up to" limits (8 spans / 3 tokens / 15%) are applied. | `budget = min(max_spans × max_span_length, floor(0.15 × len))`, then sample span lengths against that budget. | DECIDED |
| **D-02** | Span corruption | Whether span length is uniform on {1,2,3}. | Uniform on {1,2,3}, with the final span truncated so the budget is never exceeded. | DECIDED |
| **D-03** | Span corruption | Whether 15% is of padded or unpadded length. | Unpadded. Padding is applied afterwards by the collator. | DECIDED |

| **D-05** | Span corruption | Whether EOS may be masked. | No — a trailing EOS is excluded from the maskable region (`mask_eos=False`). | DECIDED |
| **D-06** | Span corruption | Whether the target ends with a trailing final sentinel. | Yes — the paper's Figure 2C shows `<extra_id_{n+1}>` terminating the target, matching T5 convention. | DECIDED (paper-supported) |
