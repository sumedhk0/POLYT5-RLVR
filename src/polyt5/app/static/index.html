polyT5 — local reproduction console

Drives the two fine-tuned checkpoints in this repository: target Tg → polymer (sampling) and polymer → Tg (beam search, width 4). Generated candidates are screened through the paper's nested SV → TSD → DD → PV cascade, scored for synthetic accessibility, and predicted back with the property model. Everything runs locally; the page makes no outside requests. Temperatures are Kelvin unless you write a unit.
